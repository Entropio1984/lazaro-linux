\chapter{Archivos PDF}\label{cap:09-pdf}

El \termino{PDF} es el formato que se usa para documentos que deben verse
igual en cualquier equipo: facturas, formularios, libros, como este
manual. Lázaro trae un visor para leerlos (\emph{Visor de documentos},
también llamado Evince; \emph{Okular} en KDE Plasma) y los abre con doble
clic.

\section{Leer}

\begin{itemize}
  \item \keys{\ctrl + +} y \keys{\ctrl + -} agrandan y achican.
  \item \keys{\ctrl + F} busca una palabra en todo el documento.
  \item \keys{F9} muestra u oculta el índice o las miniaturas de las
        páginas, a la izquierda.
  \item \keys{F11} pone el documento a pantalla completa.
\end{itemize}

\section{Rellenar un formulario}

Muchos formularios oficiales en PDF traen casillas para escribir. Ábrelo
con doble clic, haz clic en cada casilla y escribe. Al terminar, guarda
con \menu{Guardar una copia} (en Evince, en el menú de las tres rayas) y
ponle otro nombre, para conservar el original vacío.

\begin{consejo}
Si el formulario no tiene casillas (es solo una imagen del papel), ábrelo
con \textbf{LibreOffice Draw} (clic derecho, \menu{Abrir con}) y agrega
cuadros de texto con \menu{Insertar > Cuadro de texto}. Después
\menu{Archivo > Exportar a PDF}.
\end{consejo}

\section{Crear un PDF}

\begin{description}
  \item[Desde un documento] En LibreOffice: \menu{Archivo > Exportar a PDF}.
  \item[Desde cualquier programa que imprime] Elige \menu{Imprimir} y, como
    impresora, \emph{Imprimir en archivo} o \emph{PDF}. En lugar de
    imprimir, guarda un PDF.
  \item[Desde una página web] En Firefox: \menu{Menú > Imprimir} y, en
    \emph{Destino}, \menu{Guardar en PDF}.
\end{description}

\section{Unir, separar o editar}

Para tareas sencillas (sacar una página, cambiar un texto) sirve
\textbf{LibreOffice Draw}: abre el PDF, haz los cambios y exporta de nuevo
a PDF. Para unir varios PDF en uno, la tienda de aplicaciones
(capítulo~\ref{cap:13-programas}) ofrece programas como \emph{PDF Arranger}:
búscalo por su nombre.

\begin{cuidado}
Evita las páginas web que \enquote{unen o convierten PDF gratis} para
documentos con datos personales: el archivo queda en un servidor ajeno.
Hazlo en tu propio equipo.
\end{cuidado}
