\chapter{Teclas para arrancar desde el USB}\label{cap:b-teclas-arranque}

Al encender, pulsa la tecla varias veces apenas aparezca el logo. La
\emph{tecla del menú de arranque} muestra la lista de discos para elegir el
USB; la \emph{tecla de configuración} abre la BIOS o UEFI, donde se cambia
el orden de arranque y el arranque seguro. Cambian según el modelo: si no
funciona, prueba las otras de la fila.

\begin{consejo}
Si Windows arranca demasiado rápido para pulsar la tecla, desde Windows:
\menu{Configuración > Recuperación > Inicio avanzado > Reiniciar ahora},
y luego \menu{Usar un dispositivo} para elegir el USB.
\end{consejo}
