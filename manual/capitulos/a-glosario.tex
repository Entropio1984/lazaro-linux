\chapter{Glosario}\label{cap:a-glosario}

\begin{description}
  \item[Alpine Linux] La distribución liviana sobre la que está hecho
    Lázaro.
  \item[apk] El programa que instala, quita y actualiza los paquetes de
    Alpine.
  \item[Arranque seguro (Secure Boot)] Una función de los equipos UEFI que
    solo deja arrancar sistemas firmados por Microsoft. A veces hay que
    desactivarla para arrancar Lázaro.
  \item[Bandeja] La parte del panel, junto al reloj, con los iconos de la
    red, el volumen y los avisos.
  \item[BIOS] El programa que trae el equipo para encender, en los equipos
    antiguos. Ver UEFI.
  \item[Calamares] El instalador gráfico de Lázaro.
  \item[Controlador] Lo que el sistema necesita para usar una pieza del
    equipo, como el wifi o la impresora.
  \item[CUPS] El sistema de impresión de Linux.
  \item[Distribución] Cada uno de los sistemas operativos hechos con Linux:
    Ubuntu, Debian, Alpine, Lázaro\ldots
  \item[doas] Se escribe delante de una orden para ejecutarla como
    administrador. Pide tu contraseña.
  \item[Escritorio] El aspecto del sistema: la barra, el menú y las
    ventanas. Lázaro ofrece XFCE, LXQt, MATE, KDE Plasma, GNOME, Sway y
    XFCE Wayland.
  \item[Firmware] Pequeños programas que necesitan algunas piezas, como el
    wifi, para funcionar.
  \item[Flatpak y Flathub] Una forma de instalar programas que funciona en
    cualquier Linux, y la tienda gratuita donde están.
  \item[Gestor de archivos] El programa para ver y ordenar tus carpetas y
    archivos (Thunar en XFCE).
  \item[GRUB] El menú que aparece al encender y arranca el sistema.
  \item[ISO] El archivo que contiene todo el sistema, listo para grabar en
    un USB.
  \item[Kernel (núcleo)] La parte central del sistema, la que habla con el
    hardware.
  \item[Linux] La familia de sistemas operativos libres a la que pertenece
    Lázaro. En rigor, el nombre del kernel.
  \item[Memoria (RAM)] Donde el equipo guarda lo que está usando en ese
    momento. Se borra al apagar. No confundir con el disco.
  \item[NetworkManager] El programa que maneja las conexiones de red.
  \item[nouveau] El controlador libre para tarjetas de video NVIDIA.
  \item[Panel] Cada una de las barras del escritorio.
  \item[Paquete] Un programa (o una parte) listo para instalar.
  \item[Partición] Cada una de las partes en que se divide un disco.
  \item[PDF] Un formato de documento que se ve igual en cualquier equipo.
  \item[Repositorio] Un lugar en internet de donde el sistema descarga
    paquetes firmados.
  \item[SANE] El sistema de escáneres de Linux.
  \item[Sesión de prueba (live)] Lázaro funcionando desde el USB, sin
    instalar nada.
  \item[Software libre] Programas que cualquiera puede usar, estudiar,
    mejorar y compartir.
  \item[Suma de comprobación (sha256)] Un número largo que permite saber si
    un archivo llegó entero.
  \item[Terminal] Una ventana donde se escriben órdenes con el teclado.
  \item[UEFI] El reemplazo moderno de la BIOS, en los equipos desde 2012,
    aproximadamente.
  \item[USB arrancable] Una memoria USB preparada para encender un equipo
    desde ella.
  \item[zram] Memoria comprimida: hace que la RAM rinda más, a cambio de un
    poco de procesador.
\end{description}
